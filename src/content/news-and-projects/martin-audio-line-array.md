We have recently taken delivery of a Martin Audio Wavefront line array.

The W8LM is a legendary line array system. It offers flexibility for both indoor and outdoor use and, thanks to line array technology and excellent acoustic coupling, delivers consistent results over long throws and across multiple height planes. We chose the W8LM because we can offer it at an affordable hire rate, and because each box is compact and highly modular.

With this system we can cater for more theatre and conference events while benefiting from line array coverage outdoors. For larger events the W8LM works as side fills and delay towers alongside the larger W8LC line array on the main hangs. We recommend running it on Linea Research 44M20 and 48M10 amplifiers.

The system pairs the W8LM array elements with W8LMD down-fills, which complete the array efficiently without needing a J-curve.
